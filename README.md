# riptideslabs.github.io

The landing page for Riptides Labs' open-source projects, served at
https://riptideslabs.github.io/. Project sites such as
[/waterwheel/](https://riptideslabs.github.io/waterwheel/) come from their own
repos, so don't add pages at a path a repo uses.

The cards are in `src/data/projects.ts`.

```sh
npm install
npm run dev
```

Pushing to `main` deploys with `.github/workflows/pages.yml`.
